# 블랙리스트 용병단 (1~5단계 + 트위터식 타임라인)

20~30명 규모 닫힌 커뮤니티용 텍스트 웹게임입니다.

- **1단계**: 초대코드 가입/로그인 · 캐릭터 프로필(이미지 포함) · 실시간 채팅 · 관리자 페이지
- **2단계**: 고정 채널 + 유저 스레드 · 안 읽은 글 표시 · 프로필의 "내가 참여한 스레드" 목록 · 관리자의 스레드 관리
- **3단계**: d20 판정 엔진 · 클래스/레벨/스탯 · 솔로 의뢰(조사 → 전투) · 구경꾼 응원 · 전투불능 처리
- **4단계**: `# 마을 장터` — 채집(파밍) · 제작 · 도박항아리 · 상점 · 장비 · 골드/아이템 선물
- **5단계**: 파티 의뢰(방장이 모집, 2~4명) · 레이드(관리자가 엶, 최소 3명·인원 제한 없음, 보스 2페이즈)

## 실행 방법

Node.js 18 이상이 필요합니다. (22 버전에서 테스트했어요)

```bash
npm install
cp .env.example .env     # 그리고 .env 안의 ADMIN_PASSWORD 를 꼭 바꾸세요
npm start
```

브라우저에서 http://localhost:3000 을 열면 됩니다.

### 처음 시작하면
1. 서버를 처음 켤 때 **관리자 계정**(`.env` 의 `ADMIN_USERNAME` / `ADMIN_PASSWORD`)과 **초대코드 5개**가 자동으로 만들어지고, 초대코드는 터미널에 출력됩니다.
2. 관리자로 로그인하면 우측 위에 **관리자** 버튼이 보입니다. 거기서 초대코드를 더 만들 수 있어요.
3. 친구에게 초대코드를 주면, 가입 화면에서 코드 + 아이디/비밀번호 + 캐릭터 이름을 입력해 가입합니다.

> 관리자 계정은 DB에 관리자가 없을 때만 만들어집니다. 비밀번호를 바꾸고 싶으면 `.env` 를 고치고 `data/` 폴더를 지운 뒤 다시 시작하거나, 관리자 페이지의 "비번 재설정"을 쓰세요.

### 이전 단계 버전을 쓰고 있었다면
기존 `data/` 폴더를 그대로 두고 새 코드로 덮어쓴 뒤 `npm install` → `npm start` 하면 됩니다.
서버가 시작할 때 DB를 자동으로 업그레이드해요. (1단계 → 기존 채팅은 `# 전체` 채널로 이동, 2단계 → 3단계는 레벨/스탯 칸과 의뢰 테이블이 추가되고 시스템 메시지용 숨은 계정이 하나 생깁니다. 이 계정은 명단·관리자 목록에 나오지 않고 로그인도 안 돼요.)

### 테스트
```bash
npm test
```
엔진·경제 단위 테스트 → 가입·프로필·채팅·스레드·신고·뮤트/정지 등(100여 개) → 타임라인(글·답글·인용·하트·멘션·알림) → 의뢰 흐름(조사·전투·응원·타이머·전투불능·보상·재시작 복구) → 마을 장터 → 파티·레이드 순서로 임시 DB 에서 돌립니다. 일부만 돌리려면 `npm run test:engine` / `npm run test:quest` / `npm run test:party`.

## 타임라인 (트위터식 대화)

일반 대화는 채널/스레드가 아니라 **하나의 타임라인**에서 합니다. (예전 채널·스레드는 서버에 남아 있지만 화면에서는 숨겨져 있어요. 의뢰 방만 실시간 채팅을 씁니다.)

- **글쓰기**: 280자, `대사`/`지문` 선택. Ctrl+Enter 로 올리기. 내용 안의 `@캐릭터이름` 은 멘션(상대에게 알림), `#태그` 는 눌러서 모아볼 수 있어요.
- **답글**: 글을 누르면 상세 화면이 열리고 답글이 시간순으로 쌓입니다. 답글에 답글을 달면 상대 이름이 자동으로 들어가요.
- **리포스트/인용**: 🔁 버튼. 내용을 비우면 그대로 리포스트, 적으면 인용이에요.
- **하트(♡)**, **신고(⚑)**, **삭제(🗑, 내 글만 / 관리자는 전부)**
- **새 글 배너**: 다른 사람이 새 글을 올리면 맨 위에 "새 글 N개 보기"가 떠요.
- **🔔 알림**: 답글·멘션·하트·리포스트·선물. 안 읽은 개수가 메뉴와 브라우저 탭 제목에 표시됩니다.
- **🔥 요즘 이야기**: 최근 3일 인기 태그. 의뢰 결과와 마을 장터 공지는 "공식" 계정이 `#의뢰` `#장터` 태그로 타임라인에 올려요.
- **프로필**: 그 캐릭터가 쓴 글이 아래에 모입니다.
- **프로필 링크(선택)**: 내 프로필에 구글 문서·에버노트 등 주소를 하나 걸 수 있어요. http/https 주소만 받고, 다른 단원은 프로필에서 도메인을 보고 눌러 새 탭으로 엽니다. 다른 단원 프로필은 왼쪽 단원 목록(모바일은 👥 버튼)이나 글의 이름을 누르면 열려요.
- 관리자 페이지에는 "타임라인 글" 탭(삭제)과 글 신고 처리가 있어요.

## 의뢰 (3단계)

**⚔ 의뢰** 메뉴에 의뢰 목록이 뜨고, **수락**하면 그 의뢰 전용 방이 만들어집니다. 진행 로그(굴림, 라운드 결과)가 방의 채팅에 그대로 흐르기 때문에, 구경하는 사람도 "진행 중·최근 의뢰" 목록에서 들어와 같이 떠들 수 있어요.

- **조사 단계**: 행동 3번 안에 선택지를 골라 d20 판정. 성공하면 전투에 유리한 효과(적 방어도 -2 등)나 단서, 실패하면 경계도 +1(대실패는 +2). 경계도가 3이 되면 적이 먼저 덮칩니다(기습).
- **전투 단계**: 공격 / 클래스 스킬(쿨타임 3라운드) / 방어 중 하나를 고릅니다. 90초 안에 안 고르면 방어. **⏩ 지금 진행**을 누르면 바로 해결, 안 누르면 최소 10초 뒤에 해결돼서 그 사이 채팅·응원이 가능해요. 서술 한 줄은 로그에 찍히지만 보너스는 없습니다.
- **응원**: 구경꾼이 라운드마다 1번, 대상당 최대 2명까지 📣 응원하면 그 라운드 명중(스킬은 위력) +1씩.
- **라운드 로그**: ① 적 HP 변화 ② 유저 HP 변화 ③ 적의 다음 행동 예고.
- **전투불능**: HP 0이 되면 그 의뢰 방에서는 발언할 수 없고(읽기·응원은 가능), 화면이 의뢰 목록으로 이동합니다. 솔로 의뢰는 전투불능 = 실패. 타임라인에서는 정상적으로 말할 수 있어요.
- **보상**: 첫 클리어 경험치 전액, 반복은 25%. 레벨업마다 최대 HP +5, 스탯 포인트 +1(프로필에서 ＋ 로 분배, 스탯 상한 +4). 레벨은 최대 5.
- **클래스는 의뢰를 한 번 시작하면 못 바꿉니다.** 한 사람이 동시에 진행할 수 있는 의뢰는 1개.
- 서버를 껐다 켜도 진행 중인 의뢰와 타이머가 그대로 이어집니다.

### 의뢰와 규칙은 JSON 만 고치면 돼요
- `content/rules.json` — 클래스별 기본 능력치/무기/스킬, 레벨 경험치표, 난이도(DC), 전투 수치(방어도, 방패막기 등), 응원·타이머 값
- `content/quests.json` — 의뢰 목록(조사 선택지, 적 능력치와 행동 패턴, 보상, 대사). 같은 모양으로 항목을 추가하면 의뢰가 늘어나요. `mode` 는 `solo` / `party` / `raid` (아래 5단계 참고).
- 서버를 다시 시작하면 반영되고, 오타나 빠진 항목이 있으면 **어디가 문제인지 한국어로 알려주며 시작을 멈춥니다.**
- 수치를 바꾼 뒤에는 `npm run sim` 으로 클래스별 승률을 확인하세요. (예: `npm run sim -- 5000 lost-cart 1`) 지금 "사라진 짐수레"는 조사 보너스 없이 87~94%입니다.

### 관리자 [밸런스] 탭 — 숫자는 화면에서 바로
- 관리자 페이지 **밸런스** 탭에서 적 HP·방어도·공격 주사위, 스킬 쿨타임·주사위, 레벨 경험치표, 난이도 DC, 의뢰 보상, 아이템 판매가·장비 보너스, 채집 확률, 제작 재료·DC, 항아리 가격·상품 확률 등 **content 파일의 숫자를 고칠 수 있어요.**
- [저장]을 누르면 위와 같은 검사를 거쳐 **서버 재시작 없이 바로 적용**돼요. 잘못된 값이면 저장되지 않고 이유를 한국어로 보여줘요.
- 바꾼 값과 변경 기록은 `data/balance.json` 에 저장돼요(content 파일은 그대로). 그래서 새 버전 zip 으로 코드를 덮어써도 조정값은 유지됩니다. `data/` 를 지우면 조정값도 사라져요.
- 변경 기록에서 **이 변경 전으로 되돌리기 / 이 시점으로 맞추기**, 맨 위의 **모두 기본값으로** 를 쓸 수 있어요. **현재 수치 내려받기** 로 지금 적용 중인 전체 수치를 파일로 받을 수 있어요(Claude 에게 공유할 때 유용).
- 스킬 설명의 `{shieldReduce}`, `{backstabBonus}`, `{dice}` 같은 칸은 현재 수치로 자동으로 채워져요. 아이템 설명 문구(desc)는 자동으로 안 바뀌니 장비 보너스를 크게 바꿨다면 Claude 에게 문구 수정도 부탁하세요.
- 글(이름·대사)이나 구조(새 의뢰·새 적 추가)는 여전히 JSON 을 고쳐야 해요. 새로 추가된 숫자는 다음 시작부터 밸런스 탭에 자동으로 나타나요.

### 설정(.env, 선택)
`ECONOMY_FILE`(다른 경제 파일), `ECON_RATE_MAX`(장터 행동 분당 제한, 기본 40), `ROUND_DEADLINE_SEC`(라운드 제한, 기본 90), `ROUND_MIN_SEC`(최소 대기, 기본 10), `QUESTS_FILE`(다른 의뢰 파일), `RNG_SEED`(주사위 고정 — 테스트용, 운영에서는 비워두세요)

## 파티·레이드 (5단계)

**파티 의뢰** (`mode: "party"`, 기본 2~4명)
- 의뢰 게시판에서 **파티 모집**을 누르면 의뢰 방이 "모집 중"으로 생기고, 타임라인 `#의뢰` 에 모집 글이 자동으로 올라가요.
- 다른 사람은 목록의 **참가** 버튼으로 들어옵니다. 출발 전에는 **나가기** 자유, 방장은 **내보내기** 가능.
- 방장이 **출발**하면 시작. 조사 행동 수는 `3 + (인원-1)` 이고, 참가자 누구나 선택지를 고를 수 있어요. 단서는 파티 전원이 얻습니다. 전투 돌입·포기는 방장만.
- 전투는 모두가 행동을 고르면(또는 시간이 끝나면) 진행돼요. 적 HP 는 인원수에 맞춰 늘어납니다 (`rules.json` 의 `party.hpScalePerPlayer`, 기본 1인당 +60%).
- 진행 중 방장이 아닌 사람은 **이탈**할 수 있어요(보상 없음). 방장이 **포기**하면 의뢰 전체가 끝납니다.

**레이드** (`mode: "raid"`, 기본 최소 3명, 최대 제한 없음)
- 유저가 직접 시작할 수 없고, 관리자 페이지 **레이드** 탭에서 **레이드 열기** → 타임라인에 `#레이드` 공지가 올라가요.
- 유저는 의뢰 게시판 목록에서 참가. 인원이 모이면 관리자가 게임 화면에서 그 방에 들어가 **출발**을 누릅니다. (관리자는 참가하지 않아도 진행·중단 가능)
- 적에 `phase2` 를 넣으면 HP 가 `at` 비율 아래로 떨어질 때 2페이즈로 바뀌어 행동 패턴이 달라져요. 예시: "늪의 달뱀" (HP 절반 이하에서 전원 독안개).
- 같은 레이드는 **주 1회(월요일 0시 기준)만 전액 보상**, 그 주에 또 깨면 경험치·골드 25%, 아이템 없음.

**공통**
- 보상은 나눠 갖지 않고 **각자 전액**. 이겼지만 전투불능이었던 사람은 경험치 절반 (`party.koXpRatio`).
- 전투불능은 기존과 같아요: 그 방 발언 불가 + 의뢰 목록으로 이동, 부활 없음. 전원 전투불능이면 실패.
- 응원은 구경꾼과 쓰러진 동료만 할 수 있어요 (싸우는 사람은 불가).
- 모집 중인 의뢰도 "진행 중"으로 쳐서, 한 사람은 솔로·파티·레이드 합쳐 동시에 1개만.
- 클래스 잠금은 "출발한 의뢰"에 참가했을 때부터. 모집만 하고 빠졌으면 아직 바꿀 수 있어요.
- `quests.json` 에서 `minPlayers` / `maxPlayers` 로 의뢰별 인원을 바꿀 수 있어요.

## 마을 장터 (4단계)

**🏘 마을 장터** 메뉴에 탭 4개짜리 패널이 있어요. (내 가방과 장비는 프로필 화면에 있어요)

- **🧺 채집**: 체력을 1 쓰고 장소별 표로 아이템을 뽑습니다. 체력은 최대 8, 6분에 1씩 회복(접속하지 않아도 계산돼서 회복). 폐광처럼 레벨 제한이 있는 장소도 있어요.
- **🔨 제작**: 재료 + 수수료 골드로 장비를 만듭니다. d20 + 스탯으로 판정해요. 성공하면 완성(대성공이면 2개), 실패하면 수수료만 잃고, 대실패(1)면 재료 절반도 잃습니다.
- **🏺 도박항아리**: 골드를 내고 깹니다. 기댓값은 가격의 약 75~80%라서 평균적으로는 조금 손해지만, 가끔 대박이 나요. 희귀 이상 드롭과 큰 당첨은 타임라인에 공식 소식으로 공지됩니다(수다 거리).
- **💰 상점**: 아이템을 정해진 값에 팝니다. 잡템은 한 번에 팔 수 있어요. 골드는 의뢰 보상, 잡템 판매, 항아리 당첨으로 들어옵니다. 시작 골드는 100.
- **🛡 장비**: 무기·방어구·장신구 슬롯 하나씩. 명중 굴림, 방어도, 최대 HP에 보너스가 붙고, 다른 사람 프로필에도 보여요.
- **🎁 선물**: 아이템과 골드를 다른 캐릭터에게 보낼 수 있습니다(받는 사람에게 알림, 마을 장터에 공개 공지, 한마디 첨부 가능). 장착 중인 장비는 먼저 해제해야 하고, 한 시간에 20번·골드는 한 번에 5,000까지입니다.
- 모든 변경(골드·아이템 이동)은 한 번에 처리돼서 동시에 눌러도 골드가 복사되거나 음수가 되지 않아요. 음수·소수·문자 수량도 서버가 거부합니다.

### 아이템·제작법·항아리도 JSON 으로
`content/economy.json` 에 아이템(이름·등급·판매가·장비 보너스), 채집 장소 표, 제작법, 항아리 상품표, 체력 설정이 모두 들어 있어요. 틀린 아이템 id 가 있으면 어디인지 한국어로 알려주며 서버 시작을 멈춥니다. 의뢰 보상에는 `reward.gold`, `reward.items` 를 쓰면 돼요.

## 폴더 구조

```
server.js        서버 본체 (API + Socket.IO)
runs.js          의뢰 진행 (모집/조사/전투/응원/타이머/보상, 파티·레이드)
town.js          마을 장터 (채집/제작/항아리/판매/장비/선물)
feed.js          타임라인 (글/답글/인용/하트/멘션/태그/알림)
economy.js       경제 규칙 (굴림·검증·체력 계산, 순수 함수)
balance.js       관리자 밸런스 조정 (검증·즉시 반영·data/balance.json 저장·되돌리기)
engine.js        d20 판정 엔진 (DB 를 모르는 순수 함수)
db.js            DB 연결, 테이블 정의, 자동 업그레이드 (SQLite)
content/         rules.json, quests.json, economy.json  ← 기획자가 고치는 곳
tools/simulate.js  밸런스 시뮬레이션
public/          화면 (index.html, app.js, style.css, admin.*)
test/            engine / economy 단위, smoke(기본), feed(타임라인), quest(의뢰), town(장터), party(파티·레이드), balance(밸런스 조정) 테스트
data/            실행하면 생기는 폴더 — game.db 와 업로드 이미지 (git 에 올리지 마세요)
```

## 이미 들어 있는 안전장치
- 비밀번호는 scrypt 로 해시, 세션은 HttpOnly 쿠키
- 로그인/가입 시도 제한, 채팅 도배 제한, 스레드 생성 제한 (`.env` 에서 일부 조절)
- 모든 유저 입력은 화면에 `textContent` 로만 출력 (HTML 이 실행되지 않음) + CSP 헤더
- 이미지는 실제 내용으로 형식 검사 후 512×512 webp 로 다시 만들어 저장 (EXIF/위치정보 제거, SVG 거부)
- 뮤트/정지는 즉시 반영 (접속 중이어도 바로 끊김)
- 신고 버튼 → 관리자 페이지에서 확인/삭제

## 호스팅 옮길 때
- DB 와 이미지는 전부 `DATA_DIR` 폴더 안에 있습니다. 호스팅 서비스의 **영구 디스크(볼륨)** 를 붙이고 `DATA_DIR` 만 그 경로로 바꾸면 됩니다.
- 무료 티어는 재배포나 잠들었다 깨어날 때 이 폴더가 초기화될 수 있어요. 테스트용으로만 쓰세요.
- 서버는 **한 대 프로세스** 전제입니다 (접속자 목록과 도배 제한을 서버 메모리에 둠).
- HTTPS 뒤에서 돌리면 쿠키에 Secure 가 자동으로 붙습니다 (`trust proxy` 설정됨).
